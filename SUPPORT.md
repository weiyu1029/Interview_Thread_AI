# InterviewThread Support

Use the channel that matches the issue so it reaches the right place.

- Product or account support: [support@interviewthreadai.com](mailto:support@interviewthreadai.com)
- Private product feedback: [feedback@interviewthreadai.com](mailto:feedback@interviewthreadai.com)
- Partnerships and research: [partnerships@interviewthreadai.com](mailto:partnerships@interviewthreadai.com)
- Privacy requests: [privacy@interviewthreadai.com](mailto:privacy@interviewthreadai.com)
- General contact: [contact@interviewthreadai.com](mailto:contact@interviewthreadai.com)

You can also use the [private contact page](https://interviewthreadai.com/en/contact).

Use GitHub Issues only for reproducible problems that contain synthetic data.
Never publish a real resume, job post tied to a private application, interview
transcript, voice recording, email address, access token, or API key.

Report suspected vulnerabilities through
[GitHub Security Advisories](https://github.com/weiyu1029/Interview_Thread_AI/security/advisories/new),
not a public issue.
