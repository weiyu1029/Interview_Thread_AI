# Public Submission Checklist

Use this checklist before sharing InterviewThread in a directory, showcase,
competition, launch platform, or open-source collection.

## Repository and security

- [ ] The canonical repository is
  `https://github.com/weiyu1029/Interview_Thread_AI`.
- [ ] Product copy uses **InterviewThread** consistently.
- [ ] `.env`, API keys, OAuth secrets, real resumes, interview transcripts, and
  private job-search records are not included.
- [ ] `.env.example` contains placeholders only.
- [ ] Generated environments and caches such as `.venv`, `__pycache__`, build
  output, and local database files are excluded.
- [ ] `./scripts/check-public-brand.sh`, `make check`, and the web quality gates
  pass on the exact commit being submitted.

## Product presentation

- [ ] The primary link is `https://interviewthreadai.com`.
- [ ] The description identifies InterviewThread as an open-source,
  evidence-grounded AI mock interview coach.
- [ ] The walkthrough, screenshots, and social preview show the current logo and
  current product interface.
- [ ] Claims stay within the evidence boundary: the product does not invent
  achievements, predict proprietary ATS decisions, or guarantee employment.
- [ ] Beta status, known limitations, privacy boundaries, and the private
  feedback route are visible.

## Founding beta

- [ ] Link testers to `https://interviewthreadai.com/en/beta`.
- [ ] Ask testers to complete the resume + job post → Evidence Map → mock
  interview journey.
- [ ] Direct account-specific or personal-data feedback to
  `https://interviewthreadai.com/en/contact`.
- [ ] Use the public beta issue form only with synthetic data.

## Optional showcase materials

- [ ] Use `docs/kaggle_writeup.md` as the current project summary.
- [ ] Use `docs/demo_script.md` for a concise evidence-first demonstration.
- [ ] Link the 60-second walkthrough:
  `https://interviewthreadai.com/interviewthread-60-second-walkthrough.mp4`.
