# Changelog

All notable public changes to InterviewThread are documented here. The project
uses beta releases while the hosted workflow is still being validated.

## Unreleased

No public changes have been assigned to the next release yet.

## 0.1.0-beta.1

The first founding-beta release packages the evidence-to-interview workflow for
a small, feedback-driven cohort. See the complete
[release notes](docs/releases/v0.1.0-beta.1.md).

### Added

- A founding-beta guide and privacy-safe feedback issue form.
- Clear live product, beta, walkthrough, support, and contribution links.
- A CI guard that prevents retired public brand names from returning.
- A structured localization report form for the 40-language interface.

### Changed

- Unified public documentation, application titles, prompts, downloads, and
  repository links under the InterviewThread name.
- Clarified that the Next.js workspace is the canonical hosted product and the
  Streamlit application is a legacy reference implementation.

### Security

- Corrected the private vulnerability-reporting URL and reinforced the rule
  against placing candidate data or credentials in public issues.
